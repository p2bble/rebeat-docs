한국어

1. 수집·전송: 본 앱은 개인정보를 수집, 전송, 공유, 판매하지 않습니다. 앱에는 인터넷(INTERNET) 권한이 없어 기기 밖으로 데이터를 보낼 수 없습니다. 광고·분석·충돌보고 SDK를 포함하지 않습니다.

2. 기기 내 처리 및 권한 사용 목적

  • 캘린더 읽기(READ_CALENDAR): 월간 달력과 다가오는 일정을 화면에 표시. 읽기 전용, 저장·전송 없음.
  • 알림 접근(알림 리스너): 재생 중인 미디어 세션 정보(곡명 등)와 컨트롤, 그리고 알림 "개수" 표시에만 사용. 알림 제목·본문 등 내용은 읽거나 저장하지 않음.
  • 알림 게시(POST_NOTIFICATIONS), 전체 화면 알림(USE_FULL_SCREEN_INTENT): 폰이 잠긴 상태에서 스탠바이 화면을 띄우기 위함.
  • 포그라운드 서비스: 힌지 각도 센서를 감시해 반쯤 접힘 상태를 감지. 센서값은 저장·전송하지 않음.
  • 부팅 완료 수신(RECEIVE_BOOT_COMPLETED), 절전 방지(WAKE_LOCK): 재부팅 후 자동 실행 및 화면 표시 유지.
  • 다른 앱 위에 표시(SYSTEM_ALERT_WINDOW): 바깥 화면 카메라 둘레 장식 링 표시(사용자가 설정에서 직접 허용한 경우에만).
  • 다음 알람 시각: 시스템에서 읽어 화면에 표시만 함.

3. 로컬 저장: D-day, 할 일 등 리마인더는 기기 내부 저장소에만 저장됩니다. 클라우드 백업(allowBackup)은 꺼져 있어 구글 백업으로도 나가지 않습니다. 앱 삭제 시 함께 삭제됩니다.

4. 제3자 제공: 없음.

5. 권한 철회: 기기 설정 > 앱 > 권한/알림 접근에서 언제든 해제할 수 있으며, 해당 기능만 비활성화됩니다.

6. 아동: 아동을 대상으로 하지 않으며 아동의 정보를 수집하지 않습니다.

English

1. This app does not collect, transmit, share or sell personal data. It has no INTERNET permission, so no data can leave the device. No ads, analytics or crash-reporting SDKs.

2. Permissions are used on-device only:

  • Calendar (read-only): display events.
  • Notification listener: now-playing media session and notification count only; contents are never read or stored.
  • Notifications / full-screen intent: show the standby screen while the device is locked.
  • Foreground service: hinge-angle sensor monitoring; values are not stored.
  • Boot completed and wake lock: auto start and keep the screen on.
  • Draw over other apps: optional decorative ring around the cover-screen camera, only if you grant it.
  • Next alarm time: display only.

3. Reminders are stored locally in app storage. Cloud backup is disabled. Uninstalling removes all data.

4. No third-party sharing.

5. You can revoke any permission in system settings; only the related feature stops.

6. Not directed to children.

7. Changes will be posted on this page.
